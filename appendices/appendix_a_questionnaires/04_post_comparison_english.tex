\section{Post-Comparison Questionnaire: English Draft}
\label{app:questionnaires_post_comparison_english}

Participants complete these questions after both rowing conditions.

\begin{enumerate}
    \item Which representation did you prefer overall?
    \item Which representation felt more directly connected to your real ergometer movement?
    \item Which representation looked more like rowing on water?
    \item In which representation did the relation between the real handle and the virtual hands or oars feel more convincing?
    \item Which representation would you rather use again?
\end{enumerate}

\subsection*{Safety and Comfort Follow-Up}

\begin{quote}
Did either representation feel less comfortable or cause dizziness, nausea, pain, or unsafe discomfort? If yes, which one and what did you notice?
\end{quote}

\subsection*{Open Comparison Comment}

\begin{quote}
Please describe the main difference you noticed between the two rowing representations.
\end{quote}
