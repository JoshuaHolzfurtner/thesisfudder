\subsection*{Vor dem Start}

\begin{enumerate}
    \item Teilnehmende Person begruessen.
    \item Aufgabe neutral erklaeren.
    \item Einwilligung und Sicherheitscheck bestaetigen.
    \item Erklaeren, dass die Teilnahme jederzeit beendet werden kann.
    \item VR-Headset anpassen und Komfort pruefen.
    \item Rudersetup kalibrieren.
\end{enumerate}

\subsection*{Ablauf pro Bedingung}

\begin{enumerate}
    \item Erste zugewiesene Bedingung starten.
    \item Eingewoehnung in die Bewegungszuordnung erlauben.
    \item Standardisierte Ruderphase beginnen.
    \item Bedingung beenden und Headset bei Bedarf absetzen oder pausieren.
    \item Fragebogen zur Bedingung ausfuellen lassen.
    \item Kurze Pause anbieten.
    \item Ablauf fuer die zweite Bedingung wiederholen.
\end{enumerate}

\subsection*{Nach beiden Bedingungen}

\begin{enumerate}
    \item Vergleichsfragebogen ausfuellen lassen.
    \item Nach freiwilligen Zusatzkommentaren fragen.
    \item Teilnehmende Person bedanken und debriefen.
\end{enumerate}
