# AI Assistance Logs

This folder is for tracking the use of AI and large language model tools during the thesis process.

The logs support transparency for the AI Assistance Statement in Appendix E. They are process documentation only. They are not thesis evidence, study data, literature sources, or a substitute for author verification.

Each log entry should record:

- date
- tool or model, if known
- task or prompt goal
- files or thesis sections affected
- whether the output was used, rejected, or revised
- how the author checked the output
- remaining TODOs, citation gaps, or verification needs

The author remains responsible for final wording, scientific claims, study design, data collection, analysis, interpretation, and citations.
