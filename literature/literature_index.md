# Literature Index

This file serves as an index of the literature materials included in this repository. Use it to keep track of what has been imported (PDFs, extracted text, summaries) and why each source was added. By maintaining a clear index, both human and AI readers can quickly see which documents exist and how they relate to the thesis.

## Format

For each paper, provide the following information:

| Key | Type | Description | Relevance |
| --- | ---- | ----------- | --------- |
| `kilteni2012soe` | summary | Summarized notes from Kilteni et al. (2012) on sense of embodiment | Defines the subcomponents of SoE (self‑location, agency, ownership) |

**Key:** A unique identifier or citation key used consistently in the thesis (e.g., `kilteni2012soe`).  
**Type:** One of `pdf`, `txt`, or `summary` to indicate whether the file is the original PDF, extracted text, or an author‑verified summary.  
**Description:** A short sentence describing the content of the document.  
**Relevance:** How the source informs or supports the thesis.  

## Example Entry

| Key | Type | Description | Relevance |
| --- | ---- | ----------- | --------- |
| `botvinick1998rhi` | summary | Summary of Botvinick & Cohen (1998), describing the rubber hand illusion | Provides experimental evidence on how synchronous visuotactile stimulation induces body ownership |

Use this table to record each source you add to `literature/`.  Keep it up to date as new articles or books are incorporated.
