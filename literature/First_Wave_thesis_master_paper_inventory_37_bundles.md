This inventory lists the 37 paper/source Markdown bundles currently present in `literature/Zips Papers/`. It is meant as a working map for thesis drafting, not final bibliography prose.

## Priority key

- **Core green**: drives the theory/method argument.
- **Green**: strong source likely to be cited in main text.
- **Green-yellow**: useful framing/support, cite selectively.
- **Yellow**: appendix/table/one-sentence support.
- **Yellow-red / red**: archive or avoid unless a specific need appears.
- **Unclear / optional**: verify identity before relying on it.

## Core first-pass writing spine

Use these sources to drive the first actual theory draft:

- Kilteni 2012 — SoE conceptual spine.
- Botvinick & Cohen 1998 — RHI baseline.
- Kalckert & Ehrsson 2012 — ownership/agency dissociation.
- Ionta 2011 — self-location / bodily self-consciousness.
- Mottelson 2023 and/or Girondini 2025 — modern VR embodiment review support.
- Waltemate 2016 — latency / temporal congruence.
- Roth & Latoschik 2020 VEQ and/or Gonzalez-Franco & Peck 2018 — questionnaire operationalization.
- Slater 2009 + Skarbez 2017 — presence/plausibility conceptual cleanup.
- Harris 2019 + Richlan 2023 + Neumann 2018 — VR sport/action realism and fidelity framing.
- Lamb 1989 + Flood/Simpson + Soper/Hume or Baca — rowing/erg-vs-boat support.

## Related-work / appendix pile

These should mostly become a compact related-work table, not long prose: Murray 2016, Arndt 2018, Rauter 2013, Ruffaldi/SPRINT-family sources if present outside this zip set, Parton/Neumann, Hoffmann, Voskeuil, Basalp, Westra, Sigrist, and other yellow VR-rowing or feedback sources.

## Main caution

Do not let the source stack turn the thesis into a rowing-biomechanics, motor-learning, health-exergame, or VR-feedback thesis. The core remains: **erg-centered embodied action congruence vs boat-centered sport-depiction realism**.
