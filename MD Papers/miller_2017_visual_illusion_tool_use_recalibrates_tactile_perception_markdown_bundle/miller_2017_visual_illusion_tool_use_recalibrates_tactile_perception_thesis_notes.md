# Thesis notes — Miller, Longo & Saygin (2017), “Visual illusion of tool use recalibrates tactile perception”

## Citation identity

Miller, L. E., Longo, M. R., & Saygin, A. P. (2017). Visual illusion of tool use recalibrates tactile perception. *Cognition*, 162, 32–40.

## What this paper is

This paper investigates tool embodiment: the way brief tool use can recalibrate multisensory body representations.

The central question is whether tool embodiment requires actual active physical tool use, with motor commands, proprioception, and somatosensory feedback, or whether the visual experience of tool use can be enough.

The authors use a mirror visual illusion. Participants move a tool with one arm, but the mirror makes it look as if the other, stationary arm is using the tool. The study then tests whether tactile perception on the stationary arm changes as if that arm had actually used the tool.

## Why it matters for the XR rowing thesis

This is highly relevant to the “virtual oar as tool/body-action extension” thread.

Your boat-centered rowing mode visually presents an oar/action system that differs from the real physical interface:
- real user action: erg handle / seat / body movement,
- virtual action: avatar arms, oars, oarlocks, blade motion, boat-water action.

Miller et al. suggests that visual signals of tool use can be powerful enough to recalibrate tactile perception, even without matching motor/somatosensory input from the apparently tool-using limb.

This does not prove that virtual oars become part of the body schema, but it supports a cautious argument that visual tool-use information can influence body/tool representations. That is a useful bridge for why virtual oar depiction may matter beyond aesthetics.

## Core experimental logic

### Experiment 1: visual illusion of tool use

Participants viewed a mirror reflection of their right arm using a mechanical grabber tool, creating the illusion that their left arm was using the tool.

But the left arm was actually stationary:
- in Experiment 1a, it was behind the mirror,
- in Experiment 1b, it was placed down by the hip, producing stronger visual-proprioceptive conflict.

After this illusory tool use, tactile perception on the stationary left arm was recalibrated.

### Experiment 2: natural tool use

Participants actually used the tool with the arm being tested.

This produced similar tactile recalibration to the visual illusion condition.

### Experiment 3: interhemispheric plasticity control

Participants used the tool with the right arm, while the stationary left arm was tested, but without the mirror illusion.

No tactile recalibration appeared on the stationary left arm.

This argues against the effect being simple interhemispheric transfer.

### Experiment 4: passive tool holding control

Participants saw/held the tool but did not use it dynamically.

No tactile recalibration occurred.

This suggests that tool-use action, not passive holding, is critical.

### Experiment 5: sensory-conflict control

Participants saw the mirror illusion of hand-object interaction without the tool.

No tactile recalibration occurred.

This argues against the effect being caused merely by mirror-related sensory conflict.

## Core findings / cheat sheet

### 1) Visual illusion of tool use recalibrated tactile perception

The main finding:
Seeing the stationary arm as if it were using a tool recalibrated tactile distance perception on that stationary arm.

This is surprising because the tested arm did not physically use the tool.

### 2) The magnitude was comparable to natural tool use

Illusory tool use and actual tool use produced similar tactile-distance recalibration.

This supports the authors’ claim that visual tool-use signals are a strong driver of tool embodiment.

### 3) Passive holding was not enough

The effect did not appear when participants merely held the tool without using it.

This is important for the rowing/oar framing:
- it is not enough for a virtual oar to simply exist visually,
- it should be dynamically coupled to meaningful object/action interactions.

### 4) General hand-object movement was not enough

The effect did not appear when participants used the hand directly without a tool.

This indicates the effect was not merely visual movement or visual-somatosensory conflict; it was specifically related to tool-use visual signals.

### 5) Tool embodiment may be visually driven

The paper challenges the idea that tool embodiment requires active physical tool use with full somato-motor feedback.

The authors argue that visual feedback of tool use can drive recalibration of body representation.

### 6) Tool embodiment is action-dependent

The paper still supports the idea that dynamic tool use matters. Passive holding was not sufficient.

For the thesis:
- virtual oar depiction should be action-based and phase-linked,
- oar/hand/blade motion should be behaviorally meaningful,
- static oars or purely decorative oars would likely be weaker for embodiment.

## Relation to the rowing thesis

### Erg-centered mode

The erg-centered mode has strong physical input:
- real handle,
- real resistance,
- real seat,
- real proprioception,
- real body motion.

This gives it strong bottom-up action fidelity.

### Boat-centered mode

The boat-centered mode has a visually transformed tool system:
- virtual oars,
- oarlocks,
- blades,
- feather/square state,
- boat/water effects.

Miller et al. supports the idea that the visual experience of tool use can still shape body/tool representations, even when not all somatosensory feedback matches.

Potential interpretation:
The boat mode may gain embodiment-relevant support from visually coherent oar use, especially if the oar motion is dynamically coupled to the user’s stroke timing and hand/seat motion.

## Relation to body schema / tool incorporation

This paper is useful after Zigrino et al. and other body-schema/tool-use sources.

Zigrino et al. gives the conceptual overview:
- body schema is plastic,
- tool use can alter body/action representation,
- proprioception and agency are important.

Miller et al. gives a sharper empirical point:
- visual tool-use signals alone can recalibrate tactile perception,
- dynamic tool-object interaction matters,
- passive tool presence is not enough.

Together, these support a careful “body-tool-action system” framing for virtual oars.

## Relation to virtual oars and feathering/squaring

This paper does not mention rowing, oars, or feathering. But it does strengthen your argument that a virtual oar should not be a static visual accessory.

The oar should be:
- dynamically used,
- visually coupled to the user’s action,
- connected to object/world effects,
- phase-consistent with the stroke,
- meaningful as a tool.

For rowing:
- catch, drive, finish, release, recovery,
- blade-water contact,
- oarlock constraint,
- feathering/squaring,
- handle/oar timing,

are all potentially important because they make the virtual oar appear as a used tool, not merely a prop.

## Specific thesis relevance

A safe thesis sentence:

“Tool-embodiment research suggests that visual tool-use signals can themselves recalibrate body-related tactile perception. Miller et al. found that a mirror-induced visual illusion of tool use changed tactile distance perception on a stationary arm, with a magnitude comparable to actual tool use, whereas passive tool holding and non-tool hand-object movement did not. This supports treating the virtual oar in XR rowing as a potentially embodiment-relevant action tool, provided its visual behavior is dynamically coupled to the user’s stroke rather than merely displayed as a static prop.”


## Additional thesis footnote / discussion note — avatar as movement cue

This point is explicitly speculative and should be used only as a footnote, discussion nuance, or future-work idea.

During development, the author observed that seeing the avatar draw the upper body back could invite a corresponding real upper-body movement. This anecdotal observation should not be presented as evidence of motor learning. However, it is conceptually consistent with Miller et al.’s finding that visual tool-use signals can recalibrate body-related tactile perception.

A cautious thesis interpretation:

- the avatar may not only reflect the user’s movement,
- it may also act as a subtle movement cue,
- a visually coherent virtual-oar system might therefore guide posture, timing, or wrist actions,
- future work could test whether correct visual feathering/squaring cues encourage users to perform more sport-faithful wrist and hand timing.

Possible footnote wording:

“During prototype development, the author observed that seeing the avatar draw the upper body back could invite a corresponding real upper-body movement. This observation is anecdotal and should not be treated as evidence of motor learning. However, it aligns with the broader idea that visual action/tool-use cues can influence body-related perception. Future studies could investigate whether visually coherent oar actions, such as feathering and squaring at the correct stroke phases, can function not only as feedback but also as subtle movement cues for rowing technique.”

Short version:

“The virtual oar may function not only as feedback, but also as an embodied movement cue.”

Thesis-safe implication:

The erg-centered mode mostly mirrors what the user physically does. The boat-centered mode may also show what rowing should look like. This makes the boat mode potentially interesting not only as a sport-realistic depiction, but also as a future implicit technique-guidance interface.


## What not to overclaim

Do not claim this paper proves virtual oars become embodied.

Do not claim it proves ownership of tools. The paper focuses on tactile recalibration/tool embodiment, not explicit ownership of a tool.

Do not claim visual feedback is always sufficient. The paper shows visual tool-use signals can drive tactile recalibration in a specific mirror illusion task, but it does not replace all somato-motor cues.

Do not claim passive visual oars are enough. The passive-holding control suggests the opposite: dynamic use matters.

Do not use this as rowing biomechanics evidence. It is a tool-embodiment/tactile-perception paper.
